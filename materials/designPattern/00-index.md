# Design Pattern Index

## 목적

- 프로젝트 코드에서 실제로 확인 가능한 디자인 패턴 적용 지점을 정리한다.
- 과도한 해석을 피하고, 코드 근거가 명확한 패턴만 기록한다.

## 범위

- `lib_checkout/`
- `service_monitor/`

단, 본 디렉토리는 다이어그램이 아니라 패턴 분석 문서만 포함한다.

## 문서 목록

- `01-applied-patterns.md`: 현재 코드에서 확인되는 적용 패턴 목록과 근거

## 패턴 선정 기준

- 코드 파일에서 역할 분리가 명확히 드러날 것
- 팀/프레임워크 관례가 아니라 구조적 이점이 설명 가능할 것
- 문서상 목표가 아니라 현재 구현에 존재할 것
