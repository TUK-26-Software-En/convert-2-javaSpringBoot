# AI-Ops Dashboard Tabs

## Optional 탭

- `AI-Ops Overview`
- `Incident Timeline`
- `Root Cause Analysis`
- `Recommended Actions`
- `Admin Audit`

## 목적

- `AI-Ops Overview`: 최근 장애와 분석 요약
- `Incident Timeline`: 상태 변화와 로그 이벤트를 시간순으로 표시
- `Root Cause Analysis`: 규칙 기반 RCA와 선택적 LLM 보강 결과 표시
- `Recommended Actions`: 운영자 권장 조치 제공
- `Admin Audit`: 관리자 Docker 제어 이력 확인

## 표시 원칙

- AI 결과는 `advisory`로 표기한다.
- 자동 실행과 권장 조치를 명확히 구분한다.
