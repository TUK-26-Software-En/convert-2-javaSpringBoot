# AI-Ops Optional Scope

## 위치

- AI-Ops는 기본 기능이 아니라 Optional 확장 기능이다.
- 기본 시스템 구조와 모니터링 기능이 완성된 이후 단계적으로 추가한다.

## 목표

- 로그 추적
- 오류 이벤트 수집
- 상태 변화와 로그의 상관 분석
- 1차 원인 분석
- 운영자 대상 대응 가이드 제시

## 기본 범위에 포함되지 않는 것

- 완전 자동 복구
- 무제한 컨테이너 제어 자동화
- 외부 LLM에 대한 무제한 로그 전송
- 운영자 승인 없는 파괴적 조치

## Optional 1단계

- Incident 탐지
- 로그와 상태 증거 수집
- 규칙 기반 RCA
- Dashboard 표시

## Optional 2단계

- 외부 LLM 연동 가능한 구조 활성화
- 요약, 설명, 대응 제안 강화
- 규칙 기반 분석 결과에 대한 보강 설명 제공

## 운영 원칙

- AI-Ops 결과는 `advisory`로 표기한다.
- 최종 운영 조치는 관리자 승인 후 수행한다.
