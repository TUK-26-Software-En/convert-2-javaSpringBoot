# LLM Integration Boundary

## 목적

- 외부 LLM 연동은 AI-Ops 분석 설명 품질을 보강하기 위한 선택 기능이다.
- 규칙 기반 RCA를 대체하지 않고 보완한다.

## 전송 가능 정보

- 마스킹된 로그 일부
- 오류 요약
- 상태 변화 타임라인 요약
- 장애 주입 여부와 유형
- 서비스 이름과 상태 코드 수준의 메타데이터

## 전송 금지 정보

- 비밀번호
- 토큰
- JDBC 전체 접속 정보
- 개인 식별 정보
- 민감한 운영 환경 세부값
- 전체 원본 로그 덤프

## 안전 장치

- 로그 마스킹 선행
- 전송 길이 제한
- 외부 전송 기능 기본 비활성
- LLM 응답 실패 시 규칙 기반 분석으로 fallback
- AI 결과는 보조 정보로만 사용

## 구현 원칙

- LLM 연동은 인터페이스 뒤에 숨긴다.
- 특정 벤더 API에 종속되지 않도록 어댑터 패턴을 적용한다.
