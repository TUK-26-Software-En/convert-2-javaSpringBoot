# Current State

## 현재 저장소 구조

- 루트: `docker-compose.yml`
- 메인 애플리케이션: `lib_checkout/`

## 현재 기술 상태

- 메인 애플리케이션은 오래된 Spring Boot 샘플 기반이다.
- 기존 DB는 `H2` 중심이다.
- PostgreSQL 설정은 아직 없다.
- 컨테이너 구성이 아직 없다.
- 별도 모니터링 서비스가 없다.

## 현재 구조의 한계

- 기능별 패키지 구조가 없다.
- `3-Layer Architecture`가 명확하지 않다.
- Controller가 직접 DB 접근을 수행한다.
- Dashboard, 신뢰성 지표, 장애 탐지, 로그 수집 기능이 없다.
- 보안 통제와 Docker 제어 정책이 없다.

## 재구성 필요성

- 기존 코드는 샘플 수준이므로 기능 확장보다 구조 재편이 우선이다.
- 요구사항은 교육 목적의 전체 시스템 구성에 가깝기 때문에, 코드, 인프라, 모니터링, 문서를 동시에 설계해야 한다.
