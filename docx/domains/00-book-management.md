# Book Management

## 목적

- 도서 등록, 수정, 삭제, 조회, 재고 관리를 제공한다.

## 핵심 속성 초안

- 도서 ID
- 제목
- 저자
- ISBN
- 출판사
- 출판일
- 총 수량
- 대출 가능 수량
- 상태

## 주요 기능

- 도서 목록 조회
- 도서 상세 조회
- 도서 등록
- 도서 수정
- 도서 상태 변경

## 비즈니스 규칙

- ISBN 중복 정책을 정의한다.
- 총 수량은 음수가 될 수 없다.
- 대출 가능 수량은 총 수량을 초과할 수 없다.
- 대출 중인 도서를 무분별하게 삭제하지 않는다.
