# Log Redaction Policy

## 목적

- 로그 분석과 LLM 연동 과정에서 민감 정보를 보호한다.

## 마스킹 대상

- 비밀번호
- 토큰
- API Key
- JDBC 접속 정보 중 민감 필드
- 개인정보 후보 문자열
- 세션 식별자

## 처리 규칙

- 원본 로그와 외부 전송 로그를 분리한다.
- 외부 전송 전 마스킹을 강제한다.
- 길이 제한을 적용한다.
- 필요한 최소 구간만 사용한다.

## 표시 규칙

- Dashboard에서는 원본 대신 정제 로그를 우선 표시한다.
- 관리자 원본 조회 기능은 기본 범위에서 제한적으로 검토한다.
