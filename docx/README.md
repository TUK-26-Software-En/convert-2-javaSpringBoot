# Docx Index

이 디렉토리는 프로젝트의 설계 기준, 구현 규칙, 운영 기준, 기능 명세를 기록하는 공식 문서 공간이다.

## 구성

- `00-rules.md`: 프로젝트 전체 규칙
- `01-roadmap.md`: 단계별 구현 로드맵
- `02-progress-log.md`: 현재까지의 결정과 진행 기록
- `context/`: 아키텍처와 실행 환경 문맥
- `codex/`: 코드 구조와 구현 규약
- `skills/`: 실행 및 운영 플레이북
- `domains/`: 기능 도메인 명세
- `operations/`: 모니터링, 보안, 검증, 지표 운영 문서

## 운영 원칙

- 구현 변경 시 관련 `docx/*.md`를 함께 갱신한다.
- 문서의 규칙이 코드보다 우선하며, 코드가 문서와 다르면 문서를 먼저 검토한다.
- Optional 기능은 반드시 문서에 범위와 위험을 명시한다.
